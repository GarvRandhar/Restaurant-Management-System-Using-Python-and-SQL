# 🍽️ Paisa Wasool Restaurant

A full-featured restaurant management application built with Python and MySQL. It supports managing tables, orders, billing with GST, inventory, reservations, and customer loyalty points — all via a terminal interface.

---

## 🚀 Features

- User authentication (admin, manager, waiter, cashier)
- Customer and reservation management
- Menu categories and items with availability toggle
- Table assignment and real-time occupancy
- Order creation and item management
- Billing system with GST (18%) and discounts
- Payment tracking
- Inventory monitoring with low-stock alerts
- Daily sales summary and reports
- Clean terminal UI with `tabulate`

---

## 🛠️ Tech Stack

- **Python 3.8+**
- **MySQL** (with `mysql-connector-python`)
- **bcrypt** for password hashing
- **tabulate** for CLI tables
- **configparser** for database settings
