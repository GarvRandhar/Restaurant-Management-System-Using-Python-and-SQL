# Paisa Wasool Restaurant Management System

Welcome to the Paisa Wasool Restaurant Management System! This Python-based project is designed to streamline the management of a restaurant's customer orders, billing, and daily sales summary. The application uses a MySQL database to store and manage customer details, orders, and daily sales data.


# Features

Customer Management:
-------
Collect and store customer details (Name and Mobile Number).

Menu Management
----
Organized menu divided into:

Breakfast

Main Course

Dessert

Interactive selection of items and quantities.

Order Management
--------
Automatically calculate and display the total amount for each order.

Add 18% GST to the subtotal and display the grand total.

Save order details in the database.

Daily Sales Summary
------
Maintain a summary of total sales for each day.

View daily sales in a tabular format from the main menu.

User-Friendly Interface
---------
Simple menu-driven interface for ease of use.

# Prerequisites

Software:

Python 3.6+

MySQL Database Server

# Usage

Menu Options
------
Breakfast: View and order items from the breakfast menu.

Main Course: View and order items from the main course menu.

Dessert: View and order items from the dessert menu.

Print Bill: Generate a bill for the current customer and save the order details.

View Daily Summary: Display the total sales collected for each day.

Quit: Exit the application.


Example Workflow
------
Start the application.

Enter customer details.

Select menu options to place an order.

Print the bill and save order details.

View the daily sales summary (if needed).

Exit the application.
